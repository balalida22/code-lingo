# Course curricula

Every lesson contains 12 exercises; every section exam contains 25 questions. The nine revised tracks each contain 20 lessons. Python retains 18 lessons and Rust retains its 26 Book-led lessons. Total: 224 lessons and 2,688 exercises.

See [NATIVE_CURRICULA.md](NATIVE_CURRICULA.md) for the review, native topic choices, history compatibility, and validation limits. This map is regenerated by `uv run python tools/curricula/build.py`.
